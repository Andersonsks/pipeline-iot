# Pipeline de Dados com IoT e Docker

## 📌 Descrição

Projeto acadêmico desenvolvido para a disciplina Disruptive Architectures: IoT, Big Data e IA.

O objetivo deste projeto é criar um pipeline de dados capaz de processar leituras de temperatura de dispositivos IoT, armazenar em banco PostgreSQL e apresentar dashboards interativos.

---

## 🚀 Tecnologias Utilizadas

- Python
- Docker
- PostgreSQL
- Streamlit
- Pandas
- Plotly
- SQLAlchemy
- GitHub

---

## 📂 Arquivos do Projeto

- pipeline_iot.py → Processamento dos dados
- dashboard.py → Dashboard visual
- README.md → Documentação

---

## 📊 Funcionalidades

- Leitura de arquivo CSV
- Inserção no banco de dados
- Criação de dashboard
- Visualização gráfica
- Análise de dados IoT
